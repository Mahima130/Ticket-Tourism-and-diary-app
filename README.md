# Travel Tourism & Diary Application

A full-stack web application built using Spring Boot that allows users to book travel tickets, manage trips, and maintain personal travel diaries.

## Tech Stack
- Java
- Spring Boot
- Hibernate / JPA
- PostgreSQL
- Thymeleaf

## Features
- User authentication and session management
- Flight, train, and bus ticket booking
- Travel diary with image uploads
- Holiday package management

## How to Run
1. Configure database in `application.properties`
2. Run the Spring Boot application
3. Access app via browser

## Deployment
Tested using Railway and Ngrok.
